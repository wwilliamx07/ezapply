ezapply is an ai workflow for quickly tailoring resumes, cover letters, and applying to jobs.
it runs in a chrome extension and features:
- autofill applications, specifically workday application forms
    - workday forms usually are very generic, but have small differences. usually differs where 
- agent or typesafeai jev for decisionmaking, ats optimization, autofilling enum fields.
- reads repos, and writes references for all github projects the user selects
    - write md files describing each project. project is broken down into components, with a file explaining each part. for larger projects, the file tree can be more complex, with granular details as you go down the tree
    - must be strictly read only
- tailor resume, cover letter, pulling knowledge from projects and additional preferences/input provided
- agent uses mcp to autonomously read postings, tailor, documents, fill out application forms. lets the user review the cover letter and tailored resume, and the user must press the final submit.
