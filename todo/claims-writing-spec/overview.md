# A writing spec for claims and repo documentation

**What.** Write claims and repo documentation to a technical writing spec, then tailor and humanize them before
they're used in application documents.

**Why.** A consistent spec makes the knowledge base uniform; tailoring and humanizing keep the application documents
from reading like the spec.

**Plan.**
- Decide whether to adopt a spec, and which.
- Apply it in the indexing skill.
- Add the tailoring and humanizing step where resumes and cover letters draw on claims.
