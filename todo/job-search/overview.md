# Job search across the boards ezapply knows

**What.** Find new postings that fit the user, from the employers they care about, without visiting each careers
page, each captured as a posting with one word.

**Why.** Today a posting reaches ezapply only when the user opens it in the browser.

**Plan.**
- Each registry site lists jobs from its board's public job list; no scraping of aggregators.
- A watch list of employers in the profile.
- A deterministic filter, then the agent ranks; dedupe against what's been seen.
- A search tool, and one that captures a chosen posting by its URL.
