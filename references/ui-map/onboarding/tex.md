while it runs, the Terminal window to watch on a Mac, or why it failed), and Check again.

**Marker:** `css=.ob-step >> role=heading[name=/^LaTeX$/]`

| Control | When | Selector | Does | Leads to |
|---|---|---|---|---|
| Copy | no engine yet | `css=.ob-step >> role=button[name=/^(Copy\|Copied)$/]` | Copies the install command | stays |
| Install it | no engine, and ezapply can install it | `role=button[name=/^(Install it\|Installing…)$/]` | `installTex` (disabled while it runs) | stays |
| Check again | no engine yet | `role=button[name="Check again"]` | Reads the state again | stays |
