# Text selected

Text selected on one page (by mouse, or by keyboard with caret browsing), widened to whole words: a Comment button
by the selection.

**Marker:** `css=button.ez-float`

| Control | When | Selector | Does | Leads to |
|---|---|---|---|---|
| Comment | | `css=button.ez-float` | A box for the note, under the selection (or above it) | [Writing the note](comment-note.md) |
